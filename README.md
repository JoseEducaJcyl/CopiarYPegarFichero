# Copia y Procesamiento de Archivo

## Descripción
Aplicación de consola en Java que lee un archivo "datos.txt" y crea una copia "copia.txt" procesando los puntos como saltos de línea.

## Funcionalidades
- Leer archivo "datos.txt"
- Almacenar líneas en un ArrayList
- Crear archivo "copia.txt"
- Procesar puntos (.) como saltos de línea
- Copiar el contenido al nuevo archivo

## Tecnologías
- Java
- BufferedReader / FileReader
- BufferedWriter / FileWriter
- ArrayList
- Manejo de excepciones IOException
